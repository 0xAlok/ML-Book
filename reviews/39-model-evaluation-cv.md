## Thin / contradictory source points (flagged, not invented)

1. **Slide typos, fixed and logged** (chapter transcribes the corrected form): `from sklearn.linear_model import linear_regression` → `LinearRegression` (W3); `from sklearn.metrics import mean_squarred_error` → `mean_squared_error` (W3); `from sklearn.preprocessing import POlynomialFeatures` → `PolynomialFeatures` (W4; §37.9 already fixed this one too); the W3 SGDRegressor pipeline snippet has a bracket bug (`Pipeline([('feature_scaling', StandardScaler())), ('sgd_regressor', SGDRegressor())])` — the extra `)` closes the pipeline early; transcribed in correct form); "SVDRegressor" → `SGDRegressor` (W4, in the ridge/lasso search options); the W5 deck's `l1_ratio` → current sklearn keyword `l1_ratios`, and its "cs" → `Cs` (noted in §39.8, matching `reviews/38-sklearn-classification.md`); `RepeatedKfold` → `RepeatedKFold` (cosmetic).
2. **`KFold(n_splits=5, random_state=42)` without `shuffle=True`** (W3 slide): with the default `shuffle=False` the folds are deterministic contiguous blocks and `random_state` is silently inert — it takes effect only when `shuffle=True`. Transcribed as written; the caveat is cross-checked against the sklearn docs.
3. **`RidgeCV`'s "`alphas` provides the estimated regularization parameter"** (W4 slide): loose — `alphas` is the constructor's candidate list; the fitted winner is `alpha_` in current sklearn (verified against the scikit-learn 1.5/1.7 `RidgeCV` docs via web search). §37.7 already used `alpha_`; §39.8 and P9(ii) reconcile the two names via the constructor-vs-fitted-attribute distinction.
4. **"ShuffleSplit … is robust to class distribution"** (W3 slide): kept as the slide's words, with §39.5's contrast — repeated subsampling averages out split luck, but *proportion-matching* is the stratified iterators' job (the W5 deck's explicit framing).
5. **Nested cross-validation is absent from the sources** — the deck never names it. §39.10 flags it as an uncovered follow-up rather than inventing it.
6. **`GridSearchCV` `refit=True` default** (the slide's STEP 4 done automatically; `best_estimator_` ready to score): standard sklearn behavior, cross-checked — the slide describes the manual version, the W4 notebook's `sgdr_model.score(X_test_norm, y_test)` corroborates the automatic one.

8. **Chapter-constructed eg 1** (`DummyRegressor` on $y=(1,2,10,11)$): not from the course — built from the slide's own baseline estimator plus hand arithmetic [verified]. Marked as such.
