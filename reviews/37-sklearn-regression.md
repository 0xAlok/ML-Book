## Thin / contradictory source points (flagged, not invented)

1. **Slide typos, fixed and logged here** (chapter transcribes the corrected form): `mean_squarred_error` → `mean_squared_error` (§37.5); `POlynomialFeatures` → `PolynomialFeatures` (§37.9); `StandardScalar()` → `StandardScaler()` (§37.8); `from sklearn.linear_model import linear_regression` / `linear_regression()` (lowercase, used in the slide's CV snippets) → `LinearRegression` (never transcribed; the chapter uses the correct class name throughout); stray extra `)` in the slide's Pipeline snippets (`('polynomial_transform', PolynomialFeatures(degree=2))),`) → removed; `grid_search.fit(x_train.reshape(-1, 1), y_train)` → `grid_search.fit(X_train, y_train)` (the chapter's running example is already 2-D).
2. **RidgeCV's reported attribute**: the slide says "`alphas` provides the estimated regularization parameter"; sklearn's fitted attribute is `alpha_` (singular) — the chapter names `alpha_`; `alphas` is the constructor's candidate list. Deliberate correction.
3. **`include_bias=False` note** (§37.6): standard sklearn API behavior, not in the slides; kept as a one-clause supplement, flagged here.
4. **Slide simplifications kept as-recorded**: normal-equation complexity stated as $O(m^2)$ in features (the slide's claim; the $O(nm^2)$ formation cost is not discussed); SGD defaults quoted per the slides (`learning_rate='invscaling'`, `eta0=1e-2`, `max_iter=1000`) — attributed to the slides, not asserted as current-sklearn fact.
5. **Lasso `alpha` vs book `λ`**: not the same number — sklearn's Lasso normalizes the squared error by $1/(2n)$; the chapter's Note gives the exact translation ($\alpha = \lambda/(2n)$ for identical minimizers) and the solutions prove it. For ridge the translation is exact identity ($\alpha = \lambda$).
6. **CV/HPT boundary with Chapter 39**: the slides' `cross_val_score`/`cross_validate`/iterators/grid-vs-randomized material is deliberately kept to a pointer (§37.9–37.10); Chapter 39 owns it. The one-line `RidgeCV`/`GridSearchCV`-for-degree versions stay here because the dials are introduced here.
7. **Synthetic data for eg 5**: the course gives no numeric overfit demo for polynomial regression (only the warning); the 10-point/degree-9 experiment is constructed for the chapter (seed stated), method and interpretation are course-sourced (§23.9, §28.6). All numbers verified, none invented.
8. **No diagrams**: no course figure was needed; the overfit story is carried by the eg-5 table (mirroring §23.9's figure, which already exists in ch 23).
