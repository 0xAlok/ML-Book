2. **Primary:** `Transcripts/Week 7/Solving an unconstrained optimization problem (Part 1).pdf`. Used: the $(x-5)^2$ walkthrough as the running example (school method $f'(x) = 2(x-5) = 0 \Rightarrow x = 5$; the hard example $3x^6 + 2x^5 + 3x^3 + 5x^2 + 2$ with $f' = 18x^5 + 10x^4 + 9x^2 + 10x$, degree-$5$ equation, no easy solve — eg 2); the iterative idea $x_{t+1} = x_t + d$; direction must depend on $x$; $d = -f'(x)$ as the direction choice; the $\eta = 1$ oscillation $10 \to 0 \to 10 \to 0$ worked out step by step (eg 3, §10.4); the "direction is right, the amount moved is wrong" diagnosis.
3. **Primary:** `Transcripts/Week 7/Solving an unconstrained optimization problem (Part 2).pdf`. Used: the step-size analysis — $\eta_t$ must shrink but not too fast; the "direction always $1$, target $x^* = 5$, start $x_0 = 2$" example: $\eta_t = 1/2^t$ sums to $2$, stalls at $4$ (eg 4); $\eta_t = 1/(t+1)$ with $\sum \eta_t = \infty$ (harmonic) — the good schedule; the two-conflicting-objectives framing (shrink to avoid oscillation vs. keep total budget infinite).
4. **Primary:** `Transcripts/Week 7/Basic algorithm for unconstrained optimization_ Gradient Descent.pdf`. Used: the algorithm box $x_{t+1} = x_t - \eta_t f'(x_t)$ with $\eta_t = 1/(t+1)$; "gradient descent" name; first-order method (uses only derivative); local vs. global minimum with the $\exists\, \varepsilon > 0$ definition of local minimum ($f(\hat x) \le f(x)$ for $x \in (\hat x - \varepsilon, \hat x + \varepsilon)$); "why does GD stop at a local minimum" (gradient zero ⇒ update zero); "no general algorithm can guarantee global minima"; convex functions = local min implies global min (named, deferred to Ch 12 — matching the lecture's "we will revisit convex functions later").
5. **Primary:** `Transcripts/Week 7/Gradient Descent and Taylor Series.pdf`. Used: the Taylor derivation — $f(x + \eta d) = f(x) + \eta d f'(x) + O(\eta^2)$; want $\eta d f'(x) < 0$; $d = -f'(x)$ gives $-\eta f'(x)^2 < 0$ (§10.6); "local information gives global information" reading of Taylor; the "small $\eta$, drop higher-order terms" honesty.
6. **Primary:** `Transcripts/Week 7/Gradient Descent for Multivariate Functions.pdf`. Used: gradient as the vector of partials; the worked $\nabla[(x_1-40)^2 + (x_2-40)^2] = (2(x_1-40), 2(x_2-40))$ evaluated at $(5,2) = (-70,-76)$, negative gradient $(70,76)$ pointing at $(40,40)$ (eg 9's first step); the second point $(30,50) \to \nabla = (-20, 20) \to -\nabla = (20, -20)$ (not used — $(5,2)$ was enough); the update $\mathbf{x}_{t+1} = \mathbf{x}_t - \eta \nabla f(\mathbf{x}_t)$; "gradient descent works for any unconstrained problem as long as you can compute the gradient; converges to a local minimum".
7. **Primary:** `Transcripts/Week 7/Taylor Series in Higher Dimensions.pdf`. Used: multivariate Taylor $f(\mathbf{x} + \eta \mathbf{d}) \approx f(\mathbf{x}) + \eta \mathbf{d}^T \nabla f(\mathbf{x})$; $d = -\nabla f$ gives $-\lVert\nabla f\rVert^2 < 0$; descent directions = $\{\mathbf{d} : \mathbf{d}^T \nabla f < 0\}$ = the half-plane picture (eg 8); $-\nabla f$ = steepest descent ("maximum decrease for a fixed unit step"); the constraint tease (rope/fence) deliberately left to Ch 11. NOT used: nothing about Lagrange — out of scope per task.

## Uncertainties / things the reviewer should know
- **eg 10's function** $f(x,y) = x^3 - 3x + y^3 - 3y$ is *constructed*, not from any source — the sources contain no multi-critical-point 2-variable classification example. All machinery used on it ($\nabla f = \mathbf{0}$, Hessian, $2\times2$ definiteness tests) is source-derived; every number was hand-verified above.
- **The "minimize the linearization" derivation** (§10.6, second half): the lecture's argument is the Taylor sign condition $d \cdot f'(x) < 0$; the fixed-budget minimization $\min_{|u|=1} L_{x_t}(x_t + \eta u)$ uses Chapter 9's §9.4 Cauchy–Schwarz machinery, as the chapter's own arc (§9.10) promised. It is a faithful combination, not a source quote — flagged as such.
- **Semidefinite $\Rightarrow$ inconclusive** (§10.8 iv): from Ch 8 §8.7.2's $f''(c) = 0$ case, extended to the Hessian as the standard multivariable twin; flagged in-text as the twin.
- **Non-differentiable points**: the sources assume differentiability throughout; the $|x|$-kink caveat is a one-line Note, not developed.
- **Figure**: drawn originally with matplotlib for this chapter (no external reuse); the HTML comment above the image says so.
- Problem 3's phrasing "(t = 0, 1)" pins the schedule indexing $\eta_t = 1/(t+1)$ to match the lecture.
