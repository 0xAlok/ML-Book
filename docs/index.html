Foundations to Deep Learning

From foundations to deep learning — a one-stop study book

This book takes you from mathematical foundations (linear algebra, calculus, probability) through classical machine learning to neural networks and transformers — everything needed before the core deep learning and AI courses.

How to study from this book

  1. Read a chapter front to back: concept first, then the worked eg blocks.
  2. Hard topics carry a “Basically, …” line — the same idea restated as simply as possible.
  3. Do the Practice set at the end of each chapter before looking at solutions: on the web, each solution is hidden behind a click; in the PDF, solutions follow each chapter.

There is nowhere else you need to go. Links out appear only where the book itself could not explain something sufficiently.
