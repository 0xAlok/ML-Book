## Thin / contradictory source points (not invented; reported here)

1. **Three axioms vs the lectures' two.** The sources state "the two axioms" ($P(S)=1$, countable additivity) with the $[0,1]$ codomain inside the probability definition. The chapter presents Kolmogorov's standard three (adding non-negativity explicitly) and says so in one parenthetical. Standard cross-check per GOAL.md; no content invented.
2. **The "technical restriction" on events is never named.** Sources say only "ignore this restriction for now". The chapter names it ($\sigma$-algebra: closed under complement and countable unions) in one Note, marked as the standard name. One sentence, standard literature.
3. **Countable/uncountable sample spaces.** Sources define "countable sample space" (listable) but never name uncountable. §14.2 adds the finite / countably infinite / uncountably infinite trichotomy with standard examples (dart landing point, exact rainfall); probabilities on uncountable spaces are deferred to Chapter 16. Standard, one paragraph.
4. **"Disjoint events are never independent" needs $P(A),P(B)>0$.** The sources state it unconditionally (twice). It is false for the degenerate case: $\emptyset$ is disjoint from everything *and* independent of everything ($P(\emptyset\cap B)=0=0\cdot P(B)$). The chapter states the lectures' claim with the positive-probability qualification plus the $\emptyset$ fine print. This is a correction, not a contradiction — flagged for the coordinator.
5. **Roads example not used.** The Bayes deck's roads exercise ("$P$(open route A→B | no open route A→C)") is a conditional-independence problem with no worked answer in the sources; a hand-computed answer would be $(1-p^2)/(2-p^2)$, but per instructions nothing was invented from thin sources, so it was left out (the basketball free-throw problem covers geometric-series reasoning instead).
6. **Urn contents unspecified.** The two-urns examples give only the conditional probabilities ($7/13$, $5/13$, etc.), never the urn compositions. The chapter uses them exactly as given, never inferring counts.
7. **Bernoulli/Binomial/Geometric slides belong to Chapter 15.** The Bayes deck ends with named distributions; per the task's scope ruling, only the repeated-trials *machinery* (product sample spaces, sequence probabilities via independence) is used here. The sample space $\{1,2,3,\dots\}$ example (§14.2) is the only borrowing from the geometric slides, with no distribution attached.
