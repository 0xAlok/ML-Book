## Thin / contradictory source points (not invented; reported here)

1. **Deck typo in the multiplication rule.** The extracted §1.4.5 line reads "$f_{XY}(t,t') = f_{Y\mid X=t}(t')$" (missing the $f_X(t)$ factor); the surrounding die-then-coins example correctly multiplies by $1/6$. Stated correctly in the chapter ($f_{X,Y} = f_X \cdot f_{Y\mid X}$).
2. **Deck typo in the max-CDF derivation (§2.3.5).** The text writes "$F_Z(z) = P(Z \le z) = P(\min\{X,Y\} \le z)$" where $Z = \max(X,Y)$, then continues inconsistently. The clean result ($F_{\max} = F_X F_Y$ for independent RVs, also in MLF Part 5) is standard; min/max distributions are deferred to Chapter 18 per scope, so nothing was built on the garbled passage.
3. **Covariance properties beyond the definition** ($\mathrm{Cov}(aX+b,cY+d)=ac\,\mathrm{Cov}$, the $|\rho|\le 1$ proof, uncorrelated-but-dependent counterexample $Y=X^2$) are not deck-verbatim: the deck states the definition, independent ⇒ uncorrelated, and the zero-cell dependence test. Each was derived by hand and numerically verified here; the correlation bound proof via $\mathrm{Var}(U\pm V)\ge 0$ is original to the chapter.
4. **Continuous conditional-PDF worked example (eg 20)** is original (triangle region, $X\sim\mathrm{Uniform}[0,1]$, $(Y\mid X=x)\sim\mathrm{Uniform}[0,x]$): the sources give only the independent tutorial case. Joint validity, $f_Y(y)=-\ln y$, and the reverse conditional were all integrated and verified numerically (see "What was checked"). Flagged as original hand-verified content.
